# @professionai/ui

Componenti del registro **operativo** (tool interni e B2B), costruiti sulle primitive shadcn/ui (Radix) in `src/ui/`
e sui token canonici. Ogni story mostra i quattro stati obbligatori: caricamento, vuoto, errore, filtro senza risultati.
Usa la toolbar per cambiare **densità** e **tema**.

- Token: `tokens/tokens.json` → `node tokens/build.mjs` → `tokens/dist/tailwind.css`
- Decisioni: `DECISIONS.md`
- Regole del registro: `registers/operational.md`
- Archetipi di pagina: `archetypes/*.md`
- Primitiva mancante: `npx shadcn@latest add <nome>` dentro `packages/ui`, poi un wrapper in `src/components/`
