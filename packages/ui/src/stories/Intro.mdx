# @professionai/ui

Componenti del registro **operativo** (tool interni e B2B). Ogni story mostra i quattro stati obbligatori:
caricamento, vuoto, errore, filtro senza risultati. Usa la toolbar per cambiare **densità** e **tema**.

- Token: `tokens/tokens.json` → `node tokens/build.mjs`
- Decisioni: `DECISIONS.md`
- Regole del registro: `registers/operational.md`
- Archetipi di pagina: `archetypes/*.md`
